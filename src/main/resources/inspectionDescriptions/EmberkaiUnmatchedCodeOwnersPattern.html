Reports CODEOWNERS lines whose pattern matches no file or folder in the repository, usually because the path was moved or deleted. Such a line no longer requests any review, and its owners silently stop being asked.

Also reports a CODEOWNERS file that is ignored because one in an earlier location takes precedence: .github/CODEOWNERS, then CODEOWNERS, then docs/CODEOWNERS.

Excluded folders such as build/ and node_modules/ count as paths but are not searched.
